Конфиденциальность

Обновлено 18 ноября 2026 года

Эта политика описывает сайт NoizWorks и расширение MediaLatch, включая функции сборки 3.1.1. Расширение разрабатывает fs0x1337.

Сайт и обращения

Сайт размещён на GitHub Pages. В английских страницах используются шрифты Google Fonts. Хостинг и сервис шрифтов получают данные, необходимые для обработки запросов. На сайте нет аналитики и рекламных пикселей. При обращении по почте, в Telegram или GitHub разработчик получает сведения, которые вы отправите, чтобы ответить на обращение.

Данные в браузере

MediaLatch обрабатывает выбранное медиа, URL страницы и доступные сведения о публикации для сохранения файла. Настройки, история, очередь, черновики, превью, необязательная статистика и журнал хранятся в профиле браузера. Учётные данные подключений хранятся отдельно и не попадают в экспорт настроек или отчёт отладки. В настройках можно очистить данные расширения. Удаление записи не удаляет сохранённый файл.

Хранилища и публикации

Выбранные медиа, имена файлов и папок отправляются из браузера напрямую в Google Drive, Яндекс Диск или MEGA, когда вы выбираете соответствующее хранилище. Расширение использует сведения о подключении, чтобы показать аккаунт, доступное место и папку назначения. Пароль MEGA используется при входе, затем в профиле хранится зашифрованная сессия.

Для Telegram можно подключить бота или войти по QR-коду с API ID и API Hash своего приложения. Ключи приложения и сессия хранятся в зашифрованной записи IndexedDB расширения. Ключ шифрования хранится в том же профиле браузера, а пароль двухэтапной проверки используется только при входе. Для VK расширение загружает доступные для публикации сообщества. Текст и файлы черновика отправляются на выбранную площадку при явной отправке или в запланированное вами время. Отключение удаляет локальное подключение. При отключении или смене аккаунта расширение запрашивает завершение прежней сессии Telegram. Если Telegram не подтверждает выход, расширение покажет предупреждение. Завершить сессию можно в Telegram → Настройки → Устройства. Уже отправленные файлы и публикации управляются на стороне сервиса.

Поиск изображений и другие запросы

Поиск похожих сохранений работает на устройстве. Если вы выбираете Google Lens, Яндекс Картинки, SauceNAO или IQDB в окне «Найти оригинал», выбранному сервису отправляется уменьшенное JPEG-превью под именем image.jpg. Имя и адрес исходника остаются в браузере. При проверке релизов расширение обращается к GitHub. Скопированные ссылки на превью обрабатываются выбранным сервисом при открытии или отправке ссылки.

Google API Services User Data Policy и Limited Use

MediaLatch запрашивает drive.file для работы с файлами, созданными приложением или предоставленными ему пользователем. Данные Google используются для подключения аккаунта, показа доступного места и сохранения выбранных файлов. Токен хранится зашифрованным в профиле браузера. Файлы отправляются напрямую в Google Drive. MediaLatch соблюдает Google API Services User Data Policy, включая требования Limited Use, при использовании и передаче данных Google API.

Вопросы и удаление данных

Пишите на always1337@vk.com. В письме укажите проект и тип данных. Не прикладывайте токены, пароли или приватные файлы. Подробности о разрешениях браузера и сроках хранения приведены в английской политике.
